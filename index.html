Cómo publicar esta App en GitHub Pages

Puedes publicar esta calculadora online completamente gratis siguiendo estos sencillos pasos:

1 Crea un repositorio en GitHub

Entra en github.com/new y crea un repositorio llamado ChemCalc2.

2 Sube el código con la terminal

Ejecuta estos comandos en tu terminal desde la carpeta del proyecto:

git add .
git commit -m "Initial commit - ChemCalc2 App"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/ChemCalc2.git
git push -u origin main
3 Activa GitHub Pages

En tu repositorio de GitHub, ve a Settings > Pages. En Source, selecciona GitHub Actions (o Branch main / root). ¡En un minuto estará online en https://tu_usuario.github.io/ChemCalc2/!
